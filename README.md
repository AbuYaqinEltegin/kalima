# Калима — карточки арабских слов

**Сайт:** https://kalima-seven.vercel.app

Приложение для изучения арабской лексики по карточкам с интервальным повторением (SM-2).

- 18 тематических колод, 390 слов с огласовками, транслитерацией и переводом
- Озвучка слов (Web Speech API)
- Режим «Все слова подряд» — непрерывный поток повторений и новых слов
- Тест с вариантами ответа, статистика и серия дней
- Светлая и тёмная тема, работает офлайн и ставится на телефон (PWA)

## Стек

React 18, Vite 6, Tailwind CSS v4, React Router, Recharts, Vitest. Хостинг — Vercel.

## Запуск

```bash
npm install
npm run dev    # разработка
npm test       # тесты
npm run build  # сборка в dist/
```

Прогресс хранится в `localStorage` браузера.
